CLIENT DATABASE SETUP:
 
1. Install PostgreSQL on your computer
2. Open Command Prompt as Administrator
3. Navigate to PostgreSQL bin folder:
   cd "C:\Program Files\PostgreSQL\16\bin"
4. Create database:
   createdb -U postgres Testing
5. Import the database:
   psql -U postgres -d Testing -f complete_database_backup.sql
 
Alternative with pgAdmin:
1. Open pgAdmin
2. Create new database "Testing"
3. Right-click database → Restore
4. Choose complete_database_backup.sql
5. Click Restore
 
After import:
- Update .env file with your database credentials
- Run Start-Servers.bat
